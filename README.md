# مصحف المدينة الرقمي (Digital Madinah Mushaf & Voice Recorder)

تطبيق ويب تقدمي (PWA) لقراءة القرآن الكريم بالرسم العثماني برواية حفص عن عاصم (طبعة مصحف المدينة المنورة - 604 صفحات)، مع ميزة تسجيل التلاوة الشخصية وإعادة الاستماع إليها محلياً، ودعم كامل للعمل دون اتصال بالإنترنت (Offline Mode).

---

## المميزات الرئيسية (Features)

1. **عرض صفحات المصحف الشريف (Madinah Mushaf Layout)**:
   - عرض مطابق 100% للمصحف المطبوع بالمدينة المنورة (604 صفحات كاملة).
   - إبراز رأس الصفحة (اسم السورة، رقم الصفحة، رقم الجزء) وأسفل الصفحة (رقم الحزب والربع).
   - إمكانية التبديل بين صفحة واحدة أو صفحتين متقابلتين على الشاشات الكبيرة.

2. **تنقل سلس ومرن (Intuitive Arabic Navigation)**:
   - دعم السحب باللمس لليمين واليسار (Swipe gestures) على الهواتف والأجهزة اللوحية متوافقاً مع اتجاه القراءة العربي (RTL).
   - أزرار التنقل السريع (السابق / التالي).
   - شريط تمرير سريع لجميع الصفحات الـ 604.
   - فهرس عربي متكامل وشامل للسور الـ 114 مع بحث فوري يتجاهل التشكيل والهمزات، وإيضاح مكان النزول (مكية / مدنية) وعدد الآيات ورقم صفحة البداية.
   - فهرس الأجزاء الـ 30 مع بيان مطلع كل جزء والصفحات التابعة له.
   - انتقال فوري برقم الصفحة.

3. **تسجيل التلاوة الشخصية (Personal Voice Recording)**:
   - تسجيل تلاوة القارئ الشخصية لكل صفحة على حدة.
   - طلب إذن الميكروفون فقط عند رغبة المستخدم في بدء التسجيل.
   - خيارات كاملة: بدء التسجيل، إيقاف مؤقت، متابعة، إيقاف وحفظ، إلغاء ومسح.
   - مؤقت زمني دقيق ومؤشر بصري لمستوى الصوت أثناء التلاوة.
   - مشغل صوتي مدمج لإعادة الاستماع للتلاوة المسجلة أو تحميلها كملف صوتي.
   - حفظ التسجيلات محلياً في المتصفح باستخدام `IndexedDB` دون أي إرسال للخوادم أو تدخل ذكاء اصطناعي.
   - سجل تلاوات أرشيفي شامل لجميع الصفحات مع إمكانية الفلترة والتحميل والحذف.

4. **العمل دون اتصال بالإنترنت (PWA & Offline Support)**:
   - تسجيل Service Worker لتخزين الملفات الثابتة وصفحات المصحف التي تتم قراءتها تلقائياً (`Cache-First Strategy`).
   - لوحة إدارة التنزيل بدون إنترنت تسمح بحفظ الجزء الحالي أو المصحف كاملاً (604 صفحة) مسبقاً.
   - التسجيلات الصوتية تعمل 100% دون اتصال بالإنترنت لأنها مخزنة محلياً في الـ IndexedDB.

5. **أنماط القراءة والمظهر (Themes & Eye Comfort)**:
   - **الوضع النهاري (العاجي)**: يحاكي لون ورق مصحف المدينة الدافئ الفاخر.
   - **الوضع الداكن الدافئ (Sepia)**: مريح للعين في الإضاءة المتوسطة.
   - **الوضع الليلي (Dark Mode)**: مخصص للقراءة الليلية بتقليل سطوع وإجهاد العين.
   - حفظ التفضيلات محلياً في `localStorage`.
   - ميزة إبقاء الشاشة مضاءة (Screen Wake Lock API) أثناء التلاوة لمنع انطفاء الشاشة.

## البنية التقنية (Tech Stack)

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: TailwindCSS 4
- **Audio Recording**: Web Audio API + MediaRecorder API
- **Audio & Offline Storage**: IndexedDB + CacheStorage API + Service Worker (PWA)
- **Typography & Icons**: Amiri, Amiri Quran, Cairo Arabic Google Fonts & Lucide React

## مصدر بيانات القرآن الكريم ورخصتها (Quran Data Source)

- **الرواية**: حفص عن عاصم (طبعة مجمع الملك فهد لطباعة المصحف الشريف بالمدينة المنورة).
- **البيانات والصفحات**:
  - فهرس السور والأجزاء وترتيب الصفحات: بيانات مفتوحة المصدر من مشروع Tanzil.net ومجمع الملك فهد.
  - صور الصفحات العالية الدقة: خوادم مرايا متعددة مستندة إلى صفحات مصحف المدينة المنورة القياسي برخصة الاستخدام المجاني لنشر القرآن الكريم.

### كيفية استبدال أو تخصيص مصدر البيانات (Replacing Quran Data Source)

تم عزل طبقة البيانات في المجلد `src/data/` والواجهة في `src/lib/quran-data.ts`:

1. لتغيير روابط أو خوادم صور الصفحات: قم بتعديل دالة `getPageImageUrls` داخل `src/lib/quran-data.ts`.
2. لتعديل بيانات السور أو إضافة تفاصيل إضافية: قم بتعديل `src/data/surahs.ts`.
3. لتعديل بيانات الأجزاء والأحزاب: قم بتعديل `src/data/juz.ts`.

## بنية وحدة التسجيل الصوتي (Recording Architecture)

تم فصل منطق التسجيل تماماً عن واجهة المصحف:

```text
[ واجهة المستخدم: RecordingBar.tsx ]
              ↓
[ محرك التسجيل: lib/recording/recorder.ts (MediaRecorder + Web Audio API) ]
              ↓
[ قاعدة البيانات المحلية: lib/recording/storage.ts (IndexedDB) ]
              ↓
[ التصدير والتشغيل: StoredRecording / Blob Download ]
```

### ترقية أو تمديد نظام التخزين (Extending Storage to Cloud)

إذا أردت مستقبلاً حفظ التسجيلات على سحابة (مثل Firebase Storage أو S3) بدلاً من IndexedDB:
- قم بتعديل الدوال `saveRecording` و `getAllRecordings` و `deleteRecording` في `src/lib/recording/storage.ts` لترسل البيانات إلى API الخادم الخاص بك مع الاحتفاظ بنفس واجهة `Promise<VoiceRecording>`.
